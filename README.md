# Bella Ginástica — Moda Fitness

Site da Bella Ginástica, loja de moda fitness feminina da Feira do Guará, em Brasília - DF.

## Site online

Após ativar o GitHub Pages, o site ficará disponível em:

`https://p4pereira.github.io/BellaGinastica/`

## Como publicar no GitHub Pages

1. Abra **Settings** no repositório do GitHub.
2. No menu lateral, entre em **Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch **main** e a pasta **/(root)**.
5. Clique em **Save**.

O GitHub vai gerar o link do site em alguns minutos.

## Executar no computador

Abra `index.html` usando a extensão **Live Server** do VS Code.

## Páginas do projeto

- `index.html` — loja e catálogo.
- `login.html` — login da cliente.
- `cadastro.html` — cadastro da cliente.
- `host-login.html` — login do responsável.
- `admin.html` — painel para cadastrar produtos e consultar pedidos.

## Localização

Feira do Guará — Brasília, DF


Esta versão é uma demonstração estática: cadastros, produtos e pedidos são salvos somente no navegador. Para vendas reais, será necessário conectar banco de dados, autenticação segura e um provedor de pagamentos.
